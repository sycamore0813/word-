Word 格式排版助手 · 免安装版
================================

不用装 Python，解压后双击「Word格式排版助手.exe」就能用。整个文件夹可以随意挪动，
但 exe 必须和 _internal、configs 两个文件夹放在一起（别单独把 exe 拖出来）。


一、它是干什么的
----------------
把一份格式乱掉的 Word 文档，按一份「格式方案」重新排版：字体、字号、行距、
缩进、对齐、标题层级、图题表题、表格文字、页面边距、页眉页码，一次改好。
只改格式，不动文字、图片、表格内容和 EndNote 引文。


二、第一次用：先从模板里读格式（做一次就够）
--------------------------------------------
1. 打开程序，切到「提取模板格式」页；
2. 「模板文档」选一份格式正确的 Word（比如学院发的论文样板.docx）；
3. 点「提取格式方案」，会在 configs 文件夹里生成一个 .yaml，这就是格式清单。

程序自带了「论文格式.yaml」（按南昌师范学院本科毕业论文样板提取的），
如果你的要求就是这套格式，可以直接跳到第三步。


三、以后每次：排版
------------------
1. 「排版文档」页，选要改的文档；
2. 「格式方案」选那个 .yaml；
3. 点「开始排版」。结果在「输出」文件夹里，文件名后面加了「_已排版」。

第一次试手，可以用「示例」文件夹里那份格式被故意打乱的稿子。


四、封面库（新功能）
------------------

提取完不会直接丢给你，程序会**自己先验一遍**：拿刚提取的方案把模板重排一遍，
再和原模板逐页比像素（约 20 秒），在日志和弹窗里给结论：
   · 「页数一致（18 页），逐页差异 平均 0.30%，最大 1.58%」→ 通过 ✅
   · 若出现「页数不一致」或某几页差异大 → 会列出差异最大的页，说明方案没完全对上。
（同一页还有「生成空白结构稿」：只留章节骨架、删掉正文，见四点五。）
提取模板时，程序会把模板的封面整页存进「封面库」（covers 文件夹）：
校徽校名图、本科毕业论文（设计）、各条信息栏、二○二 年 月 都在库里；
但**具体题目、姓名、学号不存**，那些位置留成空白横线，谁用谁填。

库里有两种东西，缺一不可：
  · 南昌师范学院本科毕业论文_封面.yaml      每行的字体、字号、对齐、空行宽度
  · 南昌师范学院本科毕业论文_封面_images\   校徽校名图（png）
拷贝/备份封面库时，要把 _images 文件夹一起带上。

排版时在「④ 封面」里选一个封面，下面「封面怎么套」有三种：

  · 只改格式（默认）：只把封面的字体、字号、对齐、间距改成模板那样，
    文字一个字不动。适合「别人的稿子封面被改乱了，帮他恢复成学校规定样式」。

  · 重建并自动填：按封面库重排封面，并自动把本文档里的姓名、学号、题目、
    学院、专业、班级、指导教师、职称填进去；文档里没有的就留空。

  · 重建但全部留空：生成一张完整的空白封面（校徽 + 标题 + 标签 + 横线），
    打印出来手写，或者直接在 Word 里往横线上打字。

封面库里的 yaml 同样可以用记事本改：每一行的字体、字号、对齐都在里面。
如果觉得横线太长或太短，改那行 parts 里 field 后面的 width 数字即可。


四点半、封面库页面（看封面长什么样）
----------------------------------
程序上方第二个页签是「封面库」：
  · 左边列出库里所有封面（名称、行数、可填几项）；
  · 点一下，右边马上画出来——校徽、标题、横线都能看到，不用打开 Word；
  · 点「用它排版 →」直接跳回排版页并选好这张封面；
  · 排版页里换了封面，封面库页也会跟着跳到那一张（两页是连着的）。


四点七五、格式预览页面（看格式排出来什么样）
------------------------------------------
第三个页签「格式预览」看的是 .yaml 方案本身：
  · 左边选方案，右边用示例文字画出 题目 / 摘要 / 一二级标题 / 正文 /
    图题 / 表题 / 表格文字 / 参考文献 的样子；
  · 字号大小、首行缩进、行距、居中还是两端对齐，一眼能看出来；
  · 排版页里换了方案，这一页会跟着换；改完 yaml 点「重新绘制」即可。


四点九、文献引用页面（自动找论文 + 插引用 + 接入 EndNote）
--------------------------------------------------------
第四个页签「文献引用」，一次做完三件事：

① 联网找真实论文
   用 OpenAlex（免费公开学术库）检索，只留期刊论文/综述、且带 DOI 的条目；
   还会核对相关性——句子里讲「挤压膨化」，论文标题里也得真有这几个词，否则不要。

② 导出给 EndNote
   结果写到「输出\文献库\文档名_引用.ris」，另有一份 _文献清单.md 方便核对。
   在 EndNote 里：File → Import → 选 File → Files of type 选 Reference Manager (RIS)
   → 选那个 .ris → Import。也可以直接双击 .ris，EndNote 会弹导入向导。

③ 在正文合适的位置插引用
   只在正文陈述句的句末插引用（标题、摘要、关键词、图表题、参考文献都不碰），
   已有的 [1]…[7] 会自动接着编 [8][9]，并在参考文献末尾按 GB/T 7714 补上条目。

页面上能调的设置：
   · 引用几篇：一共插几处（默认 2）
   · 每段最多几处：同一段不重复堆（默认 1）
   · 引用样式：顺序编码-上标[n] / 普通[n] / 上标(n) / 作者-年份
   · 检索主题：留空=按句子自动推断；建议填英文学术词，命中率更高
     （例如 extrusion cooking cereal snack food）
   · 最早年份、是否必须有 DOI、是否只插正文、是否跳过每节首段

注意：程序插的是「上标 [n]」这样的普通文本，不是 EndNote 的域代码；
     文献入库后，如果想让 EndNote 管编号，可以在 Word 里用 Cite While You Write 重新插成域。


零、先看哪份说明
--------------
· 「排版文档」页还有个「新建空白论文（已排版）」：不用先有稿子，
  按当前方案直接生成一篇排好格式的空白论文（摘要+关键词、目录、1~6 章、
  致谢、附录、参考文献），打开就能写。
· 参考文献条目会插在「参考文献」标题下面（不是文末），并且接在已有条目后面；
  如果之前被塞到文末了，点一次「重排引用编号」就会自动挪回标题下面。
· 排版只改「格式」，不会凭空长出章节：原稿有什么章节，排完还是那些。
  想让文末自动补上「参考文献 / 致谢 / 附录」，勾选项里的
  「补齐缺失章节（参考文献/致谢/附录）」——只补缺的，已有的不动。
  想要完整结构（文献综述、研究方法、讨论…），先用「提取模板格式」页的
  「生成空白结构稿」搭骨架，再往里面写内容。
· 界面上带 **(?)** 或 **?** 的地方，鼠标停上去会弹一句解释，不用翻说明书。
  「文献引用」整页都有：要加引用的文档、检索主题、引用几篇、每段最多、最早年份、
  引用样式、必须 DOI、只插正文、跳过首段、自定义模板、RIS 文件、目标文档、参考文献格式；
  按钮也有：检索并插入引用、生成参考文献表并插入、用刚才检索到的文献生成、
  导入 .ens 样式、新建/重命名/删除/保存、导出文献分析、重排引用编号。
· 程序窗口**底部有一条「功能说明」**，会跟着你点的页签自动切换，
  告诉你「这一页是干什么的、大概怎么操作」，不用翻说明书。
  觉得占地方，点右下角「收起说明」。
· 想用「文献引用」功能：先看同目录的《参考文献引用功能说明.md》，一步步带截图。
· 只想排版：直接看下面第三节。
· 想出数据图：看五点二。


四点五、生成空白结构稿（先搭骨架，再填内容）
------------------------------------------
写论文最烦的是「结构不全」：写到一半发现没写致谢、目录对不上。

在「提取模板格式」页：
   · ① 模板文档：选学校的论文样板（或任何结构完整的稿子）；
   · 点「生成空白结构稿」，默认给你一份**通用论文大纲**：
       摘　要（+ 关键词）→ 目　录 → 1 引言 → 2 文献综述 → 3 研究方法 →
       4 结果与分析 → 5 讨论 → 6 结论与展望 → 致　谢 → 附　录 → 参考文献
     只到一级标题，**不抄模板里的小标题**；每个标题下面留空段，打开就能写。
   · 想沿用模板自己的章节（含 1.1、1.2 这些小标题）：勾选「沿用模板的章节标题」。

写完内容后，把它拿到「排版文档」页按方案排一次，格式就统一了。

命令行：python -m wordfmt.cli skeleton 模板.docx --profile configs\论文格式.yaml
       python -m wordfmt.cli skeleton 模板.docx --from-template   :: 沿用模板章节


五点二、图表页面（输入数据，自动画图）
------------------------------------
第五个页签倒数第三个「图表」，操作只有三步：

① 数据有三种来源，任选：
   · 直接粘到左边框里（第一行表头，后面每行一条，列之间用 Tab 或逗号）；
   · 点「从 Excel 读取…」选一个 .xlsx 文件，右边下拉可以选哪张工作表，
     程序会把表头和内容自动填进框里（只支持 .xlsx / .xlsm，.xls 老格式先另存）；
   · 点「从 CSV 读入…」选一个 .csv / .txt。
② 选图类型（12 种）：柱状图 / 分组柱状图 / 堆叠柱状图 / 折线图 / 面积图 /
   饼图 / 环形图 / 散点图 / 箱线图 / 水平条形图 / 热力图 / 雷达图，
   填标题、横轴、纵轴，点「画图预览」，右边马上出图。
   配色可以选现成的（学术蓝 / 暖色 / 绿色 / 灰度 / 彩虹），也可以选「自定义」
   自己填颜色代码，如 #1E6F5C,#E67E22；热力图另可选色带（Reds / Blues / viridis…）。
③ 想插进论文：选文档、填图题、填「插在哪」的标题文字，点「插入到文档」。
   图居中、宽 14cm，下面自动加一行「图N 图题」，图号接着文档里已有的往下编。
   「图题」「插在哪」右边各有一个「?」，鼠标停上去会解释这两个格该填什么：
     · 图题 = 图下面那行说明文字，只写内容（如「各月产量变化」），序号程序自动加；
     · 插在哪 = 填小节标题里的几个字，图会放在该小节的末尾。
   「图表」和「文献引用」两页内容较长，右侧有滚动条（鼠标滚轮也能滚）。

注意：「插在哪」填的是小节标题里的几个字（比如 3.1 工艺流程选择），
   程序会把图放在这一小节的末尾——不会插到正文中间，也不会丢到文末。


五点四、参考文献表（不用 EndNote 也能做）
--------------------------------------
「文献引用」页最下面有两个入口：

A. 用刚才检索到的文献（推荐，全程不碰 EndNote）
   先在上面点「检索并插入引用」，程序会把找到的文献记在内存里；
   然后在下面选目标文档，点「用刚才检索到的文献生成（不用 EndNote）」，
   程序按 GB/T 7714 拼好条目接到「参考文献」最后一条后面，
   已有 [1]…[9] 就自动编 [10]、[11]，不会重号。

小提示：插完引用后如果你又删了几处、或者手动调了顺序，编号会乱。
   点「重排引用编号」，程序按正文出现顺序重新编号（[8][9] 可能变成 [1][2]），
   参考文献表也跟着重排，一次搞定。这一步随时可以重复做。

B. 用现成的 RIS（可选）——知网文章、EndNote 导出的都走这条
   知网：文献详情页 → 导出/参考文献 → 格式选 RIS → 下载；
   EndNote：File → Export，输出样式选 RefMan (RIS) Export；
   编码不用管：程序会自动识别 GBK / UTF-8，不会乱码。
   不知道具体怎么导？点「怎么引知网文章？」，程序里会弹窗讲三条路的每一步。
   点「生成参考文献表并插入」，效果和 A 一样。

说明：EndNote 只是「文献仓库」，排参考文献这件事程序自己就能做完，
     不需要开 EndNote，也不需要双击 .ris。

参考文献格式：下拉里内置 8 种（GB/T 7714 / APA 7th / MLA 9th / Chicago /
   IEEE / Vancouver / Harvard / Nature）；选「自定义模板」可以自己写，
   占位符 {seq} {authors} {title} {journal} {year} {volume} {issue} {pages} {doi}。
   条目末尾默认不写 DOI（学校模板一般不要求）；想带上就勾「条目里带 DOI」。
   右边的「新建… / 重命名… / 删除 / 保存」可以管理自己建的格式，
   存在 configs\参考文献格式.yaml 里，可以备份、换电脑带走。
   「导入 EndNote 样式(.ens)」会读样式名和说明，自动挑最接近的内置格式
   （.ens 是私有二进制，没法 100% 还原，要完全一致就用自定义模板）。

导出文献分析：点「导出文献分析」，在 输出\文献库 生成
   文献分析.md（数量/年份跨度/DOI 比例/年份分布/期刊前10/作者前10/完整清单）
   和 文献分析_年份分布.png（可直接插进论文）。


五、想改格式
------------
configs 里的 .yaml 用记事本就能改，改完保存、重新排版即可。例如把正文改成宋体小四：

    - name: 正文
      font: {east_asia: 宋体, size: 12}
      para: {line_spacing: 1.5, first_line_chars: 2}

每一项的含义见程序「帮助」页，或随包的 README.md。


五点五、排版时自动做的几件事
--------------------------
0. 排版前先清「隐形字符」：从网页、PDF、知网复制来的文字常带零宽空格、软连字符、
   不间断空格，肉眼看不见却会让排版莫名多空、行距异常。程序动手前会先清掉，
   并在日志里告诉你清了多少个。
--------------------------
0.5 全角空格不会变方框：标题里的「1　引言」「摘　要」用的是全角空格，
   程序会让它走中文字体，不会因为西文字体缺字形而显示成小方块。
0.6 关键词只加粗「关键词：」这几个字，后面的词条是常规粗细（按你的要求）。
1. 小标题一律变黑：Word 内置的「标题 1/2/3」样式自带蓝色，程序会把颜色强制改成黑色
   （方案里没写颜色的部分都这样处理）。
2. 摘要标题单独成段：如果你的「摘  要：正文……」挤在一段里，程序会拆成
   「摘  要」标题 + 正文两段，标题按模板的摘要标题格式排，正文仍按正文格式。
3. **封面填空是真正的下划线**（不是「_」字符，也没有任何可见符号）：整条线连续，
   字打上去就在线上，不会把线断成两截；打印、转 PDF 都正常。
4. 信息栏对齐：学院 / 专业 / 学生姓名 / 指导教师 四行统一缩进、左边对齐；
   班级 / 学号 / 职称 三列用制表位对齐，填多长的字都不会挤歪。
5. 不会删你的内容：只有确认是封面（短行、无长段落、无摘要关键词）才替换封面；
   摘要、关键词、正文一律保留，摘要前面的论文题目也保留。
6. 加粗会按方案清理：方案没要求加粗的段落（如摘要正文），会去掉从原文档带来的加粗，
   免得看着像黑体。
7. 样式会带进 Word：排版后打开文档，右上角「样式」库里能看到
   「1-正文文本」「摘要标题」「关键词」「目录标题」等自定义样式，可以直接改样式统一调格式。
8. 备份只留一份：同一个文档反复排版，只在旁边生成一个「原名_备份.docx」，不会越堆越多。
9. 目录里的「目录」自己不会出现，摘要会作为一条收进目录。


六、注意事项
------------
1. 目录、页码是 Word 的「域」，要重新分页才会更新。程序会自动调用本机 Word 更新；
   如果电脑没装 Word，也能排版，只是打开文档后要按 Ctrl+A、再按 F9 刷一下页码。
2. 不选封面时，封面默认保持原样（不套样式），因为封面是自由排版，硬套通常更难看。
3. 只支持 .docx；.doc 请先在 Word 里另存为 .docx。
4. 如果杀毒软件报「未知程序」：这是 PyInstaller 打包的常见误报，添加信任即可。
5. exe 不能单独拷出来，要和 _internal、configs、covers 三个文件夹放在一起。
5. 排版前程序会自动备份原文件（文件名带「_备份_时间」）。
